# lenapub — с чего начать

Этот набор файлов — задание для Claude Code: он сам соберёт приложение **lenapub** (клиент kino.pub
для телевизора, как denopub) и поставит его на ТВ-приставку Xiaomi. От вас — нажимать кнопки на
пульте и в настройках, когда он попросит.

## Что понадобится

- Mac, подключённый к тому же Wi-Fi, что и приставка.
- Приставка Xiaomi, включённая в телевизор, и её пульт.
- Аккаунт kino.pub (логин делается кодом с телефона, пароль в приставку вводить не нужно).
- Около 1–2 часов (большую часть времени Claude работает сам).

## Шаги

1. Распакуйте папку `lenapub-kit` куда угодно, например в «Загрузки».
2. Установите Claude Code: откройте приложение **Терминал** и вставьте команду с сайта
   https://claude.com/claude-code (раздел Install), войдите в свой аккаунт Claude.
   Можно и через приложение Claude для Mac (вкладка Code).
3. В Терминале перейдите в папку набора и запустите Claude:

   ```bash
   cd ~/Downloads/lenapub-kit
   ```

   ```bash
   claude
   ```

4. Напишите ему: **«Прочитай PROMPT.md и сделай всё по нему. Общайся со мной по-русски.»**
5. Дальше он ведёт сам: попросит один раз ввести пароль от Mac (для установки Homebrew), включить
   режим разработчика на приставке, разрешить отладку, ввести код на kino.pub/device.
   Разрешайте ему выполнять команды, когда он спрашивает.

## Потом, чтобы обновить приложение

Попросите Claude Code в папке проекта (`~/Projects/lenapub`): «обнови lenapub на телевизоре» — или
в Терминале: `cd ~/Projects/lenapub && scripts/tv.sh deploy`. Приставка должна быть включена.
